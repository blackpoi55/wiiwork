# ระบบใบเสนอราคา (Next.js + TypeScript + Tailwind)

โปรแกรมทำใบเสนอราคางานซ่อม ใช้งานบนเครื่องตัวเอง **ไม่ต้องมีฐานข้อมูล** — เก็บทุกอย่างเป็นไฟล์ในโฟลเดอร์ `data/`

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

ถ้าจะใช้งานจริงแบบเร็วขึ้น ให้ build ก่อน:

```bash
npm run app
```

## สิ่งที่ทำได้

- หน้าตาแบบโปรแกรมใช้งานจริง — เมนูข้าง, การ์ดสรุปยอด, แถบค้นหา/กรอง, แจ้งเตือนมุมจอ, กล่องยืนยันก่อนลบ
- กรอกฟอร์มใบเสนอราคา (หัวเอกสาร, รายการงาน, ค่าดำเนินการ, VAT) พร้อม **ตัวอย่างเอกสารสดๆ ข้างจอ**
- รายการงานที่ใช้บ่อยเป็น **ปุ่มลัด** คลิกเดียวเพิ่มเข้าใบ
- แนบรูปความเสียหาย — เลือกหลายรูปพร้อมกัน, ลากสลับลำดับ, **ครอป/หมุน/ปรับสว่าง-คอนทราสต์** ในตัว
- กดครั้งเดียวได้ทั้ง **PDF + Excel** เก็บลงโฟลเดอร์ตามวันที่อัตโนมัติ
- เปิดใบเก่าดู/แก้ไข และ **เปิดโฟลเดอร์ที่เก็บไฟล์ใน File Explorer** ได้จากในแอป
- ค่าดำเนินการคิด 10% ของยอดรายการอัตโนมัติ (ตรงกับใบเก่าทั้งหมด) และปรับ % หรือกรอกเองได้

## โครงสร้างที่เก็บข้อมูล

```
data/
├─ ทะเบียนใบเสนอราคา.xlsx      ← เปิดใน Excel แล้ว filter หาได้ทุกใบ (มี AutoFilter ให้แล้ว)
├─ ทะเบียนใบเสนอราคา.csv
├─ settings.json                ← ข้อมูลบริษัท / ค่าตั้งต้น / รายการงานที่ใช้บ่อย
└─ quotations/
   └─ จรัญ22/                   ← โครงการ
      └─ 2026-05/               ← ปี-เดือน
         ├─ 2026-05-20_A-203/   ← วันที่_ห้อง (พิมพ์ค้นใน Explorer เจอทันที)
         │  ├─ quotation.json
         │  ├─ photos/
         │  └─ export/
         │     ├─ ใบเสนอราคา_จรัญ22_A-203_2026-05-20.pdf
         │     ├─ ใบเสนอราคา_จรัญ22_A-203_2026-05-20.xlsx
         │     └─ เวอร์ชันก่อนหน้า/   ← ไฟล์เดิมถูกเก็บไว้ทุกครั้งที่ออกใหม่
         └─ _รวมทั้งเดือน/
            └─ ใบเสนอราคา_จรัญ22_2026-05_รวมทั้งเดือน.xlsx   ← 1 sheet ต่อ 1 ห้อง
```

ชื่อโฟลเดอร์ใบงานมีทั้งวันที่และห้องอยู่ในชื่อเดียว จึงกรองได้ทั้งสองทาง:
พิมพ์ `A-203` เจอทุกครั้งที่เคยทำห้องนั้น · พิมพ์ `2026-05-20` เจอทุกห้องของวันนั้น

ย้ายที่เก็บข้อมูลได้ด้วยตัวแปรแวดล้อม `QUOTE_DATA_DIR`:

```bash
QUOTE_DATA_DIR=D:/งานใบเสนอราคา npm run dev
```

## ไฟล์ที่ออกให้

| ไฟล์ | เนื้อหา |
| --- | --- |
| PDF | หน้า 1 = ฟอร์มใบเสนอราคา, หน้าถัดไป = รูปความเสียหาย 6 รูป/หน้า (เลือก 4 รูป/หน้าได้) |
| Excel รายใบ | ฟอร์มเดียวกัน **พร้อมสูตรจริง** (`SUM`, `BAHTTEXT`) แก้ต่อใน Excel ได้ |
| Excel รวมเดือน | รวมทุกห้องของเดือนนั้นไว้ไฟล์เดียว แยก sheet ตามห้อง |

PDF เรนเดอร์ด้วย Chromium (puppeteer) โดยใช้ฟอนต์ **Angsana New / Tahoma** ของ Windows
จึงได้หน้าตาเหมือนไฟล์เดิมที่พิมพ์จาก Excel

## ตั้งค่า

หน้า **ตั้งค่า** แก้ข้อมูลบริษัท, โลโก้/ลายเซ็น (ไฟล์อยู่ใน `public/brand/`),
ค่าตั้งต้นของใบใหม่ และรายการงานที่ใช้บ่อย (ดึงมาใส่ใบได้ในคลิกเดียว)
