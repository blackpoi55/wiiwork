# ระบบใบเสนอราคา (Next.js + TypeScript + Tailwind)

โปรแกรมทำใบเสนอราคางานซ่อม ใช้งานบนเครื่องตัวเอง **ไม่ต้องมีฐานข้อมูล** — เก็บทุกอย่างเป็นไฟล์ในโฟลเดอร์ `data/`

## ติดตั้งบนเครื่องใหม่

ต้องลงแค่ **Node.js (รุ่น LTS)** อย่างเดียว → https://nodejs.org (กด Next รัวๆ ตามค่าเริ่มต้นได้เลย)
ถ้าจะใช้ `อัปเดตโปรแกรม.bat` ดึงโค้ดจาก GitHub ต้องมี [Git](https://git-scm.com) ด้วย

**ไม่ต้องลง** Microsoft Excel (ใช้แค่ตอนเปิดไฟล์), ฐานข้อมูล, Chrome, Python หรือ web server ใดๆ
Chromium ที่ใช้ทำ PDF ระบบโหลดมาให้เองตอนติดตั้ง

ฟอนต์ **Angsana New** กับ **Tahoma** ที่ทำให้ PDF หน้าตาตรงกับของเดิม ติดมากับ Windows อยู่แล้ว
(`C:\Windows\Fonts\angsana.ttc`) — **ต้องเป็น Windows เท่านั้น** ถ้ารันบน Mac/Linux เอกสารจะเพี้ยน

ขั้นตอน:

1. ลง Node.js LTS
2. เอาโค้ดลงเครื่อง — `git clone https://github.com/blackpoi55/wiiwork.git`
   หรือก๊อปปี้ทั้งโฟลเดอร์มา (ข้าม `node_modules` กับ `.next` ได้ เดี๋ยวสร้างใหม่เอง)
3. ดับเบิลคลิก `เปิดโปรแกรม.bat` — ครั้งแรกจะติดตั้งและเตรียมโปรแกรมให้เอง
4. ถ้า Windows ถาม Firewall ให้กด **Allow access** (เฉพาะกรณีจะให้เครื่องอื่นเข้าใช้)

> **ย้ายใบเสนอราคาเก่าไปด้วย:** โฟลเดอร์ `data/` ไม่ขึ้น GitHub (กันข้อมูลลูกค้าหลุด)
> ถ้า clone มาจะได้โปรแกรมเปล่าๆ — ต้องก๊อปโฟลเดอร์ `data` จากเครื่องเดิมมาวางเอง

ทรัพยากรที่ใช้: อินเทอร์เน็ตตอนติดตั้งครั้งแรก (โหลดราว **1.2 GB**) · พื้นที่ดิสก์หลังติดตั้ง **~1.5 GB**
หลังจากนั้นใช้งานแบบออฟไลน์ได้ ไม่ต้องต่อเน็ต

## เริ่มใช้งาน

**ดับเบิลคลิกไฟล์ `เปิดโปรแกรม.bat`** — ครั้งแรกจะติดตั้งและเตรียมโปรแกรมให้เอง
(ต้องมี [Node.js](https://nodejs.org) รุ่น LTS ในเครื่องก่อน) จากนั้นเบราว์เซอร์จะเปิดขึ้นมาเอง
ปิดโปรแกรมด้วยการปิดหน้าต่างสีดำ

มีการแก้โค้ดใหม่ → ดับเบิลคลิก `อัปเดตโปรแกรม.bat` (ข้อมูลใน `data/` ไม่ถูกแตะต้อง)

**เครื่องอื่นในออฟฟิศ** เปิดใช้ร่วมกันได้ผ่าน Wi-Fi/LAN เดียวกัน ที่อยู่ Network จะขึ้นในหน้าต่างสีดำ
เช่น `http://192.168.1.76:3000` — ครั้งแรก Windows อาจถาม Firewall ให้กด **Allow access**

สำหรับคนที่ถนัดคอมมานด์ไลน์:

```bash
npm install && npm run app
```

### ทำไมไม่ deploy ขึ้นเว็บ

โปรแกรมนี้ทำงานด้วยการอ่าน/เขียนไฟล์จริงในเครื่อง และเรนเดอร์ PDF ด้วยฟอนต์ **Angsana New / Tahoma
ของ Windows** เพื่อให้เอกสารหน้าตาตรงกับของเดิมเป๊ะ — จึงรันบนโฮสต์แบบ serverless (Vercel ฯลฯ) ไม่ได้
เพราะดิสก์เขียนไม่ได้ ไม่มี Chromium ให้ puppeteer และไม่มีฟอนต์ไทยชุดนั้น

## สิ่งที่ทำได้

- หน้าตาแบบโปรแกรมใช้งานจริง — เมนูข้าง, การ์ดสรุปยอด, แถบค้นหา/กรอง, แจ้งเตือนมุมจอ, กล่องยืนยันก่อนลบ
- กรอกฟอร์มใบเสนอราคา (หัวเอกสาร, รายการงาน, ค่าดำเนินการ, VAT) พร้อม **ตัวอย่างเอกสารสดๆ ข้างจอ**
- รายการงานที่ใช้บ่อยเป็น **ปุ่มลัด** คลิกเดียวเพิ่มเข้าใบ
- **ฟอร์มยืดหยุ่น** — บล็อกข้อมูลกลางฟอร์มเพิ่ม/ลบ/สลับบรรทัดได้อิสระ, เงื่อนไขไม่จำกัด 4 ข้อ,
  แถวรายการงานขยายได้ถึง 15 รายการ (บล็อกลายเซ็นเลื่อนลงตามเอง), รูปต่อหน้าเลือกได้ 2/4/6/9

### ตัวแปรในฟอร์ม

ช่องข้อความในบล็อกข้อมูลกลางฟอร์มพิมพ์ตัวแปรแทรกได้ ระบบแทนค่าจริงให้ตอนออกเอกสาร:

`{{ลูกค้า}}` `{{ที่อยู่}}` `{{วันที่}}` `{{ผู้ขอเสนอราคา}}` `{{PO}}` `{{ห้อง}}` `{{โครงการ}}`
`{{เลขที่เอกสาร}}` `{{จำนวนแผ่นรูป}}`

เช่นบรรทัด "สิ่งที่ส่งมาด้วย" ตั้งไว้ว่า `เอกสารภาพความเสียหาย แนบประกอบจำนวน {{จำนวนแผ่นรูป}} แผ่น`
จำนวนแผ่นจะนับตามรูปที่แนบให้เองทุกครั้ง
- แนบรูปความเสียหาย — เลือกหลายรูปพร้อมกัน, ลากสลับลำดับ, **ครอป/หมุน/ปรับสว่าง-คอนทราสต์** ในตัว
- กดครั้งเดียวได้ทั้ง **PDF + Excel** เก็บลงโฟลเดอร์ตามวันที่อัตโนมัติ
- เปิดใบเก่าดู/แก้ไข และ **เปิดโฟลเดอร์ที่เก็บไฟล์ใน File Explorer** ได้จากในแอป
- ค่าดำเนินการคิด 10% ของยอดรายการอัตโนมัติ (ตรงกับใบเก่าทั้งหมด) และปรับ % หรือกรอกเองได้

## โครงสร้างที่เก็บข้อมูล

```
data/
├─ ทะเบียนใบเสนอราคา.xlsx      ← เปิดใน Excel แล้ว filter หาได้ทุกใบ (มี AutoFilter ให้แล้ว)
├─ ทะเบียนใบเสนอราคา.csv
├─ settings.json                ← ข้อมูลบริษัท / ค่าตั้งต้น / รายการงานที่ใช้บ่อย
└─ quotations/
   └─ จรัญ22/                   ← โครงการ
      └─ 2026-05/               ← ปี-เดือน
         ├─ 2026-05-20_A-203/   ← วันที่_ห้อง (พิมพ์ค้นใน Explorer เจอทันที)
         │  ├─ quotation.json
         │  ├─ photos/
         │  └─ export/
         │     ├─ ใบเสนอราคา_จรัญ22_A-203_2026-05-20.pdf
         │     ├─ ใบเสนอราคา_จรัญ22_A-203_2026-05-20.xlsx
         │     └─ เวอร์ชันก่อนหน้า/   ← ไฟล์เดิมถูกเก็บไว้ทุกครั้งที่ออกใหม่
         └─ _รวมทั้งเดือน/
            └─ ใบเสนอราคา_จรัญ22_2026-05_รวมทั้งเดือน.xlsx   ← 1 sheet ต่อ 1 ห้อง
```

ชื่อโฟลเดอร์ใบงานมีทั้งวันที่และห้องอยู่ในชื่อเดียว จึงกรองได้ทั้งสองทาง:
พิมพ์ `A-203` เจอทุกครั้งที่เคยทำห้องนั้น · พิมพ์ `2026-05-20` เจอทุกห้องของวันนั้น

ย้ายที่เก็บข้อมูลได้ด้วยตัวแปรแวดล้อม `QUOTE_DATA_DIR`:

```bash
QUOTE_DATA_DIR=D:/งานใบเสนอราคา npm run dev
```

## ไฟล์ที่ออกให้

| ไฟล์ | เนื้อหา |
| --- | --- |
| PDF | หน้า 1 = ฟอร์มใบเสนอราคา, หน้าถัดไป = รูปความเสียหาย 6 รูป/หน้า (เลือก 4 รูป/หน้าได้) |
| Excel รายใบ | ฟอร์มเดียวกัน **พร้อมสูตรจริง** (`SUM`, `BAHTTEXT`) แก้ต่อใน Excel ได้ |
| Excel รวมเดือน | รวมทุกห้องของเดือนนั้นไว้ไฟล์เดียว แยก sheet ตามห้อง |

PDF เรนเดอร์ด้วย Chromium (puppeteer) โดยใช้ฟอนต์ **Angsana New / Tahoma** ของ Windows
จึงได้หน้าตาเหมือนไฟล์เดิมที่พิมพ์จาก Excel

## ตั้งค่า

หน้า **ตั้งค่า** แก้ข้อมูลบริษัท, โลโก้/ลายเซ็น (ไฟล์อยู่ใน `public/brand/`),
ค่าตั้งต้นของใบใหม่ และรายการงานที่ใช้บ่อย (ดึงมาใส่ใบได้ในคลิกเดียว)
